# hi 👋

Frontend engineer working where **design systems** meet **creative development** — I like turning fuzzy design intent into typed, tested, shipped systems, and using the browser as a place to explore ideas.

### Design systems & tooling

- **[haus](https://github.com/hipuku/haus)** — a token-first React design system: W3C DTCG + OKLCH tokens, 12 accessible components, [live Storybook](https://haus.hipuku.dev).
- **[haus-colour-utils](https://www.npmjs.com/package/haus-colour-utils)** — my published perceptual-colour package (CIEDE2000, WCAG contrast, OKLCH scales). Consumed by the projects below, not just published.
- **[drift](https://github.com/hipuku/drift)** — a design-system auditor that crawls any live site and reports the design system it *actually ships* — every colour, type, and spacing value, deduplicated and diagnosed. Playwright + a Redis job queue + WebSockets.
- **[vault](https://github.com/hipuku/vault)** — an offline Mac app for capturing and shaping design tokens (colours, fonts, palettes, type scales). Electron + typed IPC + SQLite.

### Creative dev — computer science in a visual context

- **[specifi](https://specifi.hipuku.dev)** — a from-scratch CSS Selectors Level 4 parser that visualises specificity.
- **[hexicon](https://hexicon.hipuku.dev)** — perceptual colour tools: CIEDE2000 naming, OKLCH palette analysis, WCAG contrast.
- **[gray-scott](https://gray-scott.hipuku.dev)** — real-time reaction-diffusion, simulated off-thread in a Web Worker.
- **[kern](https://kern.hipuku.dev)** — the shared component library and token layer behind the experiments.

### Toolbox

`TypeScript` · `React` · `Node` · `Electron` · `Playwright` · `CSS` (OKLCH, design tokens) · testing (Vitest, Cucumber, K6)
