## Tools

Free, in the browser, no sign-up, MIT licensed.

<table>
<tr>
<td width="50%" valign="top">
<a href="https://tokenise.hipuku.dev"><img src="assets/tokenise.png" alt="tokenise"></a>
<p>Converts design tokens between DTCG, Figma variables, Tokens Studio and Tailwind v4, and reports every token each format changes or drops.</p>
<a href="https://tokenise.hipuku.dev">Open</a> · <a href="https://github.com/hipuku/tokenise">Source</a>
</td>
<td width="50%" valign="top">
<a href="https://specifi.hipuku.dev"><img src="assets/specifi.png" alt="specifi"></a>
<p>CSS specificity, token by token, on a from-scratch Selectors Level 4 parser.</p>
<a href="https://specifi.hipuku.dev">Open</a> · <a href="https://github.com/hipuku/specifi">Source</a>
</td>
</tr>
<tr>
<td width="50%" valign="top">
<a href="https://hexicon.hipuku.dev"><img src="assets/hexicon.png" alt="hexicon"></a>
<p>Names any hex by CIEDE2000, maps a palette in OKLCH and draws a WCAG contrast matrix for every pair.</p>
<a href="https://hexicon.hipuku.dev">Open</a> · <a href="https://github.com/hipuku/hexicon">Source</a>
</td>
<td width="50%" valign="top">
<a href="https://gray-scott.hipuku.dev"><img src="assets/gray-scott.png" alt="gray-scott"></a>
<p>Real-time Gray-Scott reaction-diffusion, simulated in a Web Worker.</p>
<a href="https://gray-scott.hipuku.dev">Open</a> · <a href="https://github.com/hipuku/gray-scott">Source</a>
</td>
</tr>
</table>

All four are built on **[kern](https://github.com/hipuku/kern)**, a component library and token
set distributed as TypeScript source at a pinned git tag.
[Storybook](https://kern.hipuku.dev) · [Case study](https://www.hipuku.dev/work/kern)
